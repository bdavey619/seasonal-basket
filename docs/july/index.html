The meals

Your usual meals, wearing July.

Keep what you already make. Add what's ripe.

Rice bowl → Tomatoes, cucumber, basil on top. It tastes like you planned it.
  • Tomato + basil Start here.
  • Tomato + cucumber If dinner just needs to be easy.
  • Tomato + corn + lime If you picked up sweet corn.
  • Tomato + avocado If you have half an avocado left.
All of it →
Pasta → Tomatoes, basil, olive oil. No jar. July does the work.
  • Tomatoes + basil This is probably the version you'll make most often.
  • Tomatoes + red pepper flakes If you want a little more from it.
  • Tomatoes + white beans + basil If there's no protein in the house.
All of it →
Tacos → Corn, tomato, cucumber, lime. Brighter than any jar.
  • Tomato + lime Start here.
  • Tomato + corn + lime If you picked up corn.
  • Tomato + cucumber + avocado If it's been a hot week.
  • Tomato + corn + cheese + hot sauce If you're cooking for two.
